Partner logos live in this folder.

Current files: xbox.png, bethesda.png, havelsan.png, aselsan.png, flight-simulator.png

To replace a logo, overwrite the file with the same name (SVG or PNG with a transparent
background). If you switch to SVG, also change data-logo="....png" to ".svg" for that
partner in index.html (section "Partners and suppliers").

The site shows every logo in one matching silver tone, so the original colors do not matter.
If a file is missing, the company name is shown as text instead.

To add a partner, copy a <li class="partner" data-logo="..."> line in index.html and add
the logo file here.
